What is HistoEnder?

HistoEnder is an automated microscope slide autostainer created by modifying a Creality Ender-3 3D printer. It's inexpensive, modular, and can simultaneously stain up to 23 slides.

Web Application

The HistoEnder Pro web app simplifies G-Code generation for staining protocols and provides direct USB control through Web Serial API.

Proven Results

H&E staining results from HistoEnder are indistinguishable from manually stained sections, while reducing hands-on time from 1 hour to under 5 minutes.

What is HistoEnder?

The Problem & Solution

Small to medium-sized histology & pathology laboratories worldwide waste hours of labor by manually performing staining procedures that could be easily automated. Commercial automated stainers typically cost €2,000-€10,000, making them impractical for non-intensive work.

The HistoEnder solves this by converting a low-cost Creality Ender-3 3D printer (under €200) into a fully functional automated slide stainer. The machine retains its 3D printing capabilities and can be reverted in less than a minute.

Key Features

  • Low Cost: Total cost under €200 including printer
  • Easy Setup: Only two 3D-printed parts needed
  • High Capacity: Stains up to 23 slides simultaneously
  • Versatile: Can perform various staining protocols (H&E, Giemsa, PAS, etc.)
  • Dual Function: Maintains full 3D printing capabilities
  • Open Source: All designs and software are openly available

How It Works

The HistoEnder is a fully programmable Cartesian FDM 3D printer that moves a slide rack loaded with microscope slides through different solvent/staining jars in a specific sequence with precise timing.

1
Hardware Modification

Two 3D-printed parts are added: a jar holder for the printer bed and a headpiece for mounting the slide holder on the printhead.

2
Software Control

G-Code controls the printer's movements to dip slides into jars at precise positions and for specific durations.

3
Staining Process

The printer automatically moves slides through up to 8 staining jars in programmed sequence and timing.

Getting Started Guide

Prerequisites

  • Creality Ender-3 3D printer
  • 3D printer filament (PETG recommended, ~450 grams)
  • Standard histological staining jars (8 jars)
  • Microscope slide holder (up to 23 slides)
  • Computer with internet access

Step-by-Step Setup

1
Print the Parts

Print the two required parts: jar holder and headpiece. Use PETG filament for durability.

Material: PETG
Jar holder dimensions: 46.4 x 102.5 x 100 mm
Space between cutouts: 6.0 mm
2
Assemble the HistoEnder

Mount the jar holder on the printer bed and the headpiece on the printhead. Use the alignment guide for precise positioning.

Raise position: Z=250 mm (travel height)
Dip position: Z=130 mm (submerged)
3
Prepare Staining Jars

Place up to 8 staining jars in the holder. Standard jar size: 45.6 x 101.3 x 93.4 mm.

4
Load Slides

Load up to 23 microscope slides into the slide holder and mount it on the headpiece.

5
Generate G-Code

Use the HistoEnder Pro web application to generate G-Code for your staining protocol.

6
Run the Program

Transfer G-Code to printer via SD card or use Web Serial for direct USB control.

G-Code Generation Guide

Understanding G-Code

G-Code is the programming language that controls 3D printer movements. The HistoEnder Pro app generates complete G-Code sequences for automated staining.

Important: All generated G-Code includes safety headers and the jar holder installation sequence. Always verify G-Code before running.

Generated G-Code Structure

1
Safety Headers
G90 ; Absolute positioning
M106 S0 ; Fan off
M302 S0 ; Allow cold extrusion
G28 ; Home all axes
2
Jar Holder Installation

Includes pause for installing jar holder and audible start beeps.

G1 Z250 F5000 ; Safe height for installation
G1 X33 Y169.5 ; Jar 1 position
M0 ; PAUSE - Install jar holder
M300 S660 P200 ; Start beep
3
Staining Sequence

For each active jar, moves to position, dips to Z=130, waits, then raises to Z=250.

; Jar 1: Haematoxylin
G1 Z250 F5000
G1 X33 Y169.5 F500
G1 Z130 ; Dip position
G4 S900 ; Wait 900 seconds
G1 Z250 F5000 ; Raise
4
Program Completion

Returns to start position, sounds completion beeps, and pauses for jar removal.

Web Serial Control Guide

What is Web Serial API?

Web Serial API allows web applications to communicate with serial devices (like your HistoEnder) directly via USB, eliminating the need for SD cards.

Browser Support: Web Serial API is supported in Chrome 89+, Edge 89+, and Opera 76+. Not available in Safari or Firefox.

Connection Process

1
Connect USB Cable

Connect your HistoEnder to your computer using a USB cable (same as for 3D printing).

2
Click "Connect USB"

In the web app, click the green "Connect USB" button in the Direct USB Control panel.

3
Select Device

Your browser will show a device selection dialog. Choose your HistoEnder (usually appears as "USB Serial Device" or similar).

4
Generate G-Code

Configure your protocol and generate G-Code as usual.

5
Send to Printer

Click "Send G-Code" to transmit the program directly to your HistoEnder. Monitor progress in the response panel.

Troubleshooting Web Serial

The "Connect USB" button is disabled or not showing

Your browser may not support Web Serial API. Try Chrome or Edge. Also ensure you're accessing the page via HTTPS (required for Web Serial).

Device not appearing in selection dialog

1. Check USB cable connection
2. Ensure HistoEnder is powered on
3. Try different USB port
4. Restart browser
5. Check if device appears in your operating system's device manager

Connection drops during G-Code sending

1. Use a high-quality USB cable
2. Avoid touching/moving cable during transfer
3. Close other applications using serial ports
4. Reduce transfer speed by adding delays in settings

Troubleshooting Guide

Common Issues & Solutions

Slides not dipping into jars properly

Possible causes:
1. Incorrect Z-height settings (should be Z=130 for dip)
2. Jar holder misaligned on print bed
3. Headpiece not securely mounted
Solutions:
- Run G28 homing command first
- Use alignment guide for jar holder positioning
- Verify Z-offset in G-Code

G-Code not running on printer

Possible causes:
1. SD card formatting issues
2. Corrupted G-Code file
3. Printer firmware compatibility
Solutions:
- Format SD card as FAT32
- Regenerate G-Code in web app
- Update printer firmware
- Try direct USB connection instead

Staining results inconsistent

Possible causes:
1. Timing discrepancies due to Z-axis movement speed
2. Reagent evaporation or contamination
3. Slide positioning variations
Solutions:
- Account for Z-axis movement in timing (add 2-3 seconds)
- Cover jars when not in use
- Ensure slides are securely mounted

Printer movements jerky or inaccurate

Possible causes:
1. Loose belts or pulleys
2. Over-tightened components
3. Mechanical binding
Solutions:
- Perform regular 3D printer maintenance
- Check belt tension and pulley screws
- Lubricate Z-axis rod
- Run calibration prints

Maintenance Checklist

  • Weekly: Clean jar holder, check for reagent spills, inspect slide holder
  • Monthly: Lubricate Z-axis rod, check belt tension, clean print bed
  • As needed: Re-level print bed, calibrate extruder, update firmware
  • After staining: Clean all components that contacted reagents

Frequently Asked Questions

How much does HistoEnder cost?

The total cost is under €200, including the Creality Ender-3 printer and materials for 3D-printed parts. This compares to €2,000-€10,000 for commercial automated stainers.

How many slides can it stain at once?

HistoEnder can stain up to 23 microscope slides simultaneously. The headpiece is designed to accommodate standard slide holders available on the market.

Can I still use it as a 3D printer?

Yes! The HistoEnder retains complete 3D printing functionality and can be reverted back to a normal 3D printer in less than 1 minute by removing the two added parts.

What staining protocols are supported?

The web app includes H&E, Giemsa, and PAS protocols, but any staining protocol can be created. HistoEnder has also been adapted for TEM grid staining.

How accurate are the staining results?

H&E staining results from HistoEnder are indistinguishable from manually stained sections. The main limitation is accounting for Z-axis movement speed in timing calculations.

Is technical knowledge required?

Basic 3D printing knowledge is helpful for setup. The web app makes G-Code generation simple, but understanding G-Code basics allows for advanced customization.

What are the main limitations?

Three main limitations: 1) Print bed size limits to 8 jars, 2) Headpiece holds max 23 slides, 3) Z-axis speed affects precise timing.

Can it be used for other applications?

Yes! HistoEnder can be used in chemistry and material science for surface modifications and dip coating. The EnderScope project shows similar 3D printer repurposing for microscopy.
