Documentation Introduction

Introduction to HistoEnder Pro

Welcome to the complete documentation for HistoEnder Pro - the web-based G-Code generator and control interface for automated histological staining systems.

What is HistoEnder Pro?

HistoEnder Pro is a comprehensive web application designed to generate and manage G-Code for automated histological staining systems based on modified 3D printers. It provides an intuitive interface for configuring staining protocols, generating optimized G-Code, and controlling connected HistoEnder devices via Web Serial API.

Note: HistoEnder Pro is based on the original HistoEnder research by Marco Ponzetti et al., which demonstrated that a standard Creality Ender-3 3D printer can be converted into a fully functional automated slide stainer for under €200.

Key Features

Protocol Management

Create, edit, and save staining protocols with customizable timing and reagent configurations for up to 8 staining jars.

G-Code Generation

Automatically generate optimized G-Code with safety headers, installation sequences, and precise timing controls.

Direct USB Control

Connect directly to HistoEnder devices via Web Serial API for real-time control without SD cards.

Documentation Quick Start Guide

Quick Start Guide

Get started with HistoEnder Pro in less than 5 minutes with this step-by-step guide.

First-Time Setup

Follow these steps to set up and start using HistoEnder Pro:

Step 1: Access the Application

Open your web browser and navigate to the HistoEnder Pro application URL. The application runs entirely in your browser, no installation required.

Browser Requirements: For Web Serial API functionality (direct USB control), use Chrome 89+, Edge 89+, or Opera 76+. HTTPS connection is required for Web Serial.

Step 2: Configure Your First Protocol

  1. Select a pre-defined protocol from the dropdown menu (H&E, Giemsa, PAS, or Custom)
  2. Review the default timing for each jar (displayed in seconds)
  3. Click "Apply" to load the protocol configuration
  4. Optionally edit reagent names by clicking the "Edit" button on any jar

Step 3: Generate G-Code

  1. Click "Generate G-Code" to create the staining program
  2. Review the generated G-Code in the preview panel
  3. Use "Dry Run" to test with reduced timing (2 seconds per step)
  4. Click "Download .gcode" to save the file to your computer

Step 4: Transfer to HistoEnder

Using SD Card

  1. Insert the SD card into your computer
  2. Copy the downloaded .gcode file to the SD card
  3. Safely eject the SD card and insert it into your HistoEnder
  4. On the HistoEnder display, navigate to "Print from SD"
  5. Select your G-Code file and start the print

Using Direct USB Connection

  1. Connect your HistoEnder to your computer via USB cable
  2. In HistoEnder Pro, click "Connect USB" in the Direct USB Control panel
  3. Select your HistoEnder from the device list when prompted
  4. Once connected, click "Send G-Code" to transmit directly
  5. Monitor progress in the printer response panel

Step 5: Run the Staining Protocol

  1. Ensure your HistoEnder is properly set up with jar holder and headpiece
  2. Load up to 23 microscope slides into the slide holder
  3. Place up to 8 staining jars in the holder positions
  4. Start the G-Code program
  5. The HistoEnder will automatically execute the staining sequence

Documentation API Reference

API Reference

Complete reference for HistoEnder Pro JavaScript API and Web Serial integration.

JavaScript API

HistoEnder Pro exposes a JavaScript API for programmatic control and integration. All functions are available in the global HistoEnderPro namespace.

Core Functions

Function HistoEnderPro.generateGCode(protocol, dryRun)
Generates G-Code from a protocol configuration. Returns a string containing the complete G-Code.
JavaScript
// Example: Generate G-Code from protocol const protocol = { name: "H&E Staining", times: [300, 120, 120, 120, 600, 30, 180, 45], reagents: [ "Xylene", "100% Ethanol", "95% Ethanol", "Tap Water", "Haematoxylin", "Tap Water", "Eosin Y", "95% Ethanol" ], reverseDehydration: true }; const gcode = HistoEnderPro.generateGCode(protocol); console.log(gcode); // For dry run (testing) const testGcode = HistoEnderPro.generateGCode(protocol, true);
Function HistoEnderPro.downloadGCode(gcode, filename)
Triggers download of G-Code as a .gcode file. Returns boolean indicating success.
Function HistoEnderPro.loadProtocol(protocolId)
Loads a protocol from the protocol database by ID. Returns protocol object or null.

Web Serial API Integration

HistoEnder Pro provides a wrapper around the Web Serial API for easier printer communication.

Function HistoEnderPro.connectPrinter(options)
Connects to a HistoEnder device via Web Serial. Returns a Promise that resolves to a connection object.
JavaScript
// Example: Connect to printer and send G-Code async function runStainingProtocol() { try { // Connect to printer const connection = await HistoEnderPro.connectPrinter({ baudRate: 115200, bufferSize: 1024 }); // Generate G-Code const protocol = HistoEnderPro.loadProtocol('HE-001'); const gcode = HistoEnderPro.generateGCode(protocol); // Send to printer await connection.sendGCode(gcode); // Monitor progress connection.on('response', (data) => { console.log('Printer:', data); }); connection.on('complete', () => { console.log('Staining complete!'); connection.disconnect(); }); } catch (error) { console.error('Connection failed:', error); } } // Event listeners HistoEnderPro.on('printerConnected', (port) => { console.log('Connected to:', port.getInfo()); }); HistoEnderPro.on('printerDisconnected', () => { console.log('Printer disconnected'); });

Protocol Management API

Function HistoEnderPro.saveProtocol(protocol, name)
Saves a protocol to local storage. Returns protocol ID.
Function HistoEnderPro.listProtocols(filter)
Returns array of saved protocols, optionally filtered by category.
Function HistoEnderPro.exportProtocols(format)
Exports all protocols in specified format (JSON, CSV, XML). Returns data string.

Configuration API

Function HistoEnderPro.getConfig(key)
Retrieves configuration value. Returns value or null.
Function HistoEnderPro.setConfig(key, value)
Sets configuration value. Returns boolean indicating success.
JavaScript
// Example: Configuration management // Set printer coordinates HistoEnderPro.setConfig('jarCoordinates', [ {x: 33, y: 169.5}, // Jar 1 {x: 86.5, y: 169.5}, // Jar 2 {x: 140, y: 169.5}, // Jar 3 {x: 193.5, y: 169.5}, // Jar 4 {x: 193.5, y: 60}, // Jar 5 {x: 140, y: 60}, // Jar 6 {x: 86.5, y: 60}, // Jar 7 {x: 33, y: 60} // Jar 8 ]); // Set safety parameters HistoEnderPro.setConfig('safety', { safeZHeight: 250, dipHeight: 130, travelSpeed: 5000, dipSpeed: 500 }); // Get current configuration const coords = HistoEnderPro.getConfig('jarCoordinates'); const safety = HistoEnderPro.getConfig('safety');

Event System

HistoEnder Pro uses an event-driven architecture. Available events include:

{lines, success, errors}
Event Description Callback Parameters
protocolLoaded Fired when a protocol is loaded {id, name, protocol}
gcodeGenerated Fired when G-Code is generated {gcode, protocol, time}
printerConnected Fired when printer connects via Web Serial {port, info}
printerDisconnected Fired when printer disconnects {}
gcodeSent Fired when G-Code is sent to printer
error Fired when an error occurs {type, message, details}
JavaScript
// Example: Event handling HistoEnderPro.on('protocolLoaded', (data) => { console.log(`Loaded protocol: ${data.name} (${data.id})`); updateUI(data.protocol); }); HistoEnderPro.on('gcodeGenerated', (data) => { console.log(`Generated ${data.gcode.length} bytes of G-Code`); console.log(`Generation time: ${data.time}ms`); }); HistoEnderPro.on('printerConnected', (data) => { console.log(`Connected to printer:`, data.info); updateConnectionStatus(true); }); HistoEnderPro.on('error', (error) => { console.error(`Error [${error.type}]: ${error.message}`); showError(error.message); }); // Remove event listener const handler = (data) => console.log(data); HistoEnderPro.on('gcodeSent', handler); HistoEnderPro.off('gcodeSent', handler);
Advanced Usage: For integration with external systems, HistoEnder Pro can be loaded as an ES6 module or embedded in iframes. See the "Extending Functionality" section for details.
Documentation G-Code Specification

G-Code Specification

Complete reference for HistoEnder Pro G-Code commands and syntax.

G-Code Basics

G-Code is the programming language used to control CNC machines and 3D printers. HistoEnder Pro generates G-Code optimized for staining automation on modified Creality Ender-3 printers.

Note: HistoEnder Pro G-Code is compatible with Marlin firmware (standard on Creality Ender-3). All coordinates use absolute positioning (G90).

Generated G-Code Structure

All HistoEnder Pro G-Code follows this structure:

G-Code
; ============================================== ; HISTOENDER PRO G-CODE ; Generated: 2024-01-15 14:30:00 ; Protocol: H&E Staining ; ============================================== ; SAFETY HEADERS G90 ; Absolute positioning M106 S0 ; Fan off M302 S0 ; Allow cold extrusion G28 ; Home all axes ; JAR HOLDER INSTALLATION G1 Z250 F5000 ; Safe height for installation G1 X33 Y169.5 ; Move to Jar 1 position M0 ; PAUSE - Install jar holder M300 S660 P200 ; Start beep 1 M300 S660 P200 ; Start beep 2 M300 S660 P200 ; Start beep 3 G4 S5 ; Safety delay ; STAINING PROCEDURE ; Jar 1: Xylene G1 Z250 F5000 ; Raise to safe height G1 X33 Y169.5 F500 ; Move to Jar 1 G1 Z130 ; Lower to dip height G4 S300 ; Dwell for 300 seconds G1 Z250 F5000 ; Raise to safe height ; Additional jars follow same pattern... ; PROGRAM COMPLETE M300 S440 P400 ; Completion beep 1 M300 S440 P400 ; Completion beep 2 M300 S440 P400 ; Completion beep 3 G1 X33 Y169.5 F500 ; Return to Jar 1 G1 Z250 F5000 ; Safe height M0 ; PAUSE - Remove jar holder

G-Code Command Reference

Command Description Parameters Example
G90 Absolute positioning mode None G90
G28 Home all axes X, Y, Z (optional) G28 or G28 X Y
G0/G1 Linear move X, Y, Z, F (feed rate) G1 X100 Y100 F5000
G4 Dwell/pause P (ms) or S (seconds) G4 S300 (pause 300s)
M0 Unconditional stop None M0
M106 Fan control S (0-255 speed) M106 S0 (fan off)
M300 Play beep tone S (frequency), P (duration ms) M300 S440 P200
M302 Cold extrusion control S (0=allow, 1=disallow) M302 S0

Coordinate System

HistoEnder uses the standard Creality Ender-3 coordinate system with custom jar positions:

G-Code
; JAR COORDINATES (mm) ; Jar 1: X33, Y169.5 ; Jar 2: X86.5, Y169.5 ; Jar 3: X140, Y169.5 ; Jar 4: X193.5, Y169.5 ; Jar 5: X193.5, Y60 ; Jar 6: X140, Y60 ; Jar 7: X86.5, Y60 ; Jar 8: X33, Y60 ; HEIGHT PARAMETERS ; Safe travel height: Z=250mm ; Dip height: Z=130mm ; Bed surface: Z=0mm ; FEED RATES (mm/min) ; Travel between jars: F=5000 ; Positioning moves: F=500

Custom G-Code Templates

Advanced users can create custom G-Code templates. The template system uses handlebars-style syntax:

G-Code Template
; Custom Template: {{protocol.name}} ; Generated: {{timestamp}} G90 M106 S0 M302 S0 G28 ; Installation sequence G1 Z{{config.safeZHeight}} F{{config.travelSpeed}} G1 X{{coordinates[0].x}} Y{{coordinates[0].y}} M0 {{#each config.startBeeps}} M300 S{{this.frequency}} P{{this.duration}} {{/each}} G4 S5 ; Staining sequence {{#each protocol.jars}} {{#if this.time}} ; Jar {{@index_1}}: {{this.reagent}} G1 Z{{../config.safeZHeight}} F{{../config.travelSpeed}} G1 X{{../coordinates[@index].x}} Y{{../coordinates[@index].y}} F{{../config.positionSpeed}} G1 Z{{../config.dipHeight}} G4 S{{this.time}} G1 Z{{../config.safeZHeight}} F{{../config.travelSpeed}} {{/if}} {{/each}} ; Completion {{#each config.completionBeeps}} M300 S{{this.frequency}} P{{this.duration}} {{/each}} G1 X{{coordinates[0].x}} Y{{coordinates[0].y}} F{{config.positionSpeed}} G1 Z{{config.safeZHeight}} F{{config.travelSpeed}} M0

Error Handling and Safety

All generated G-Code includes safety features:

G-Code
; SAFETY FEATURES G90 ; Prevent relative positioning errors M106 S0 ; Turn off fan (not needed for staining) M302 S0 ; Allow cold extrusion (no hotend heating) G28 ; Home before starting (ensures known position) ; BOUNDARY CHECKS ; All moves are validated against printer limits: ; X: 0-220mm (Ender-3 bed size) ; Y: 0-220mm ; Z: 0-250mm ; ERROR RECOVERY ; M0 pauses allow manual intervention ; Beep sequences indicate progress ; Program returns to start position on completion
Important: Always verify generated G-Code before running on your HistoEnder. Use the "Dry Run" feature for testing with reduced timing. Ensure proper jar holder installation before starting any staining protocol.
